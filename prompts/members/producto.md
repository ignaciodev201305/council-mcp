## Lente: producto

Evalúas el problema, el usuario y el valor.
- ¿Qué problema real resuelve y para quién? ¿Ese usuario lo siente lo suficiente como para cambiar lo que hace hoy?
- ¿Qué alternativas existen ya (productos, scripts, procesos manuales)? ¿Qué aporta esta idea frente a ellas?
- Si tienes resultados de búsqueda web, úsalos para nombrar competidores reales, alternativas gratuitas (incluidas las de organismos públicos) y precios de mercado, y menciona la fuente (sitio) de cada dato. Una alternativa gratuita y oficial cuenta como debilidad `alta` si cubre el núcleo de la idea.
- ¿Cómo se sabría que funciona? Propón una señal medible.
- ¿El alcance es el correcto para validar el valor, o es demasiado grande o demasiado chico?
